# Security policy

Please report vulnerabilities privately, not in a public issue.

- Use GitHub's private vulnerability reporting for this repository (Security tab, "Report a vulnerability"), or
- email **jjrpfister@gmail.com** with "Loam security" in the subject.

Include what you found, how to reproduce it, and what you think the impact is. This is a one-person project: expect an acknowledgement within a week and a fix or a plan after that. Please don't test against other people's accounts or data, and don't run load tests against the live site.

In scope: the API (`app/`), the web app (`frontend/`), and the deployment scripts. Out of scope: the third-party services Loam uses (Firebase, Tailscale, GitHub, CARTO, OpenStreetMap) and reports without a demonstrated impact.
